# Groq-only mode

This project is configured for Groq-hosted chat by default.

- Default users use the deployment Groq key.
- Power users can paste their own Groq key.
- Vigzone tracks per-user daily usage and enforces the configured app-level cap.
- The usage modal shows used tokens, remaining tokens, request count, reset countdown, and plan.

Use `README_GROQ_PRODUCTION_V2.md` for deployment variables.
