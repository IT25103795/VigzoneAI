## Customization Guide

After Vigzone builds your website, you can easily customize:

### Colors
- Find CSS variables at the top of the style section
- Change hex codes (e.g., `#0066CC` → `#FF6B35`)
- All colors update throughout the site automatically

### Typography
- Change font families in the `font-family` declarations
- Update font sizes by modifying the px values
- Google Fonts links are already included

### Content
- Replace text directly in HTML elements
- Swap images by updating `<img>` src attributes
- Add/remove sections by duplicating and editing HTML blocks

### Layout
- Modify flexbox/grid properties for different arrangements
- Change breakpoints in media queries for different responsive behavior
- Adjust spacing with padding/margin CSS properties

## Performance Tips

### Optimize Images
- Use web-friendly formats (WebP, JPEG, PNG)
- Compress images before adding to your site
- Use `srcset` for responsive images

### Minimize External Dependencies
- Stick with CSS (no heavy frameworks) for simple sites
- Use vanilla JavaScript instead of jQuery when possible
- Keep bundle size small for faster loading

### Lazy Load Content
- Load images only when they come into view
- Defer non-critical JavaScript
- Use native `loading="lazy"` attribute on images

## Getting Help

### Common Questions

**Q: Can I use this with a CMS like WordPress?**
A: Yes! Export the HTML/CSS, import into WordPress as a custom theme, or use as a starting point.

**Q: Can I add authentication/user accounts?**
A: For simple needs, use Supabase or Firebase. For complex apps, Vigzone can generate React/Vue components.

**Q: How do I make the contact form send emails?**
A: Use FormSubmit, Formspree, or Netlify Forms for free email handling.

**Q: Can I integrate with a backend API?**
A: Absolutely! Vigzone can generate JavaScript/React code that fetches from your API.

**Q: How do I add a blog section?**
A: Vigzone can build the design; pair with a CMS like Contentful, Strapi, or a simple JSON data file.
